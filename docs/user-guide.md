# User Guide

## Create a project

Dashboard → New project → name it. Open it to enter the canvas-first workspace.

## Floor plan & scale

Upload a PNG/JPEG/SVG plan (Settings/Design inspector or the empty-state prompt).
Use the Scale tool: click two points on a known distance, enter its real length.
(PDF: upload a PNG/JPEG export of the page — documented limitation.)

## Walls

Press W (or the Wall tool). Click to add vertices; double-click or Enter to
finish; Escape cancels the segment, a second Escape exits. Shift constrains the
angle; Alt disables snapping; type a number for an exact segment length. The
material stays selected so you can draw another wall. Select a wall to drag it,
drag vertices, double-click a segment to insert a vertex, or a vertex to remove
it. Right-click a wall for material/split/door/window actions.

## Access points

Press A or use the Catalog to place APs. Drag to move. Double-click an AP (or
right-click → Edit) to open Properties / Radios / Pattern tabs. Change Model
opens the selector (search/filter/compare) and shows a compatibility summary
before applying — the change is undoable.

## Analysis

Pick a band (2.4/5/6) and a heatmap metric, then Simulate. Hover to inspect a
point (status bar). The Requirements workspace estimates capacity and can
auto-plan channels.

## Scenarios & export

Inventory/Reports workspace: clone/compare scenarios and view the BOM. Export
menu produces a PDF report, CSV inventory/BOM, and JSON snapshots.

All RF results are predictive estimates — validate with an on-site survey.
